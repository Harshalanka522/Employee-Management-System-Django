# 👨‍💼 Employee Management System

A Full Stack Employee Management System built using **Django**, **Python**, **MySQL**, **HTML**, **CSS**, and **JavaScript**.

## ✨ Features

- 👨 Employee Management
- 🏢 Department Management
- 📅 Attendance Management
- 💰 Salary Management
- 📊 Dashboard
- 🔐 Authentication & Authorization
- 🔍 Search & Pagination
- ⚡ Automatic Net Salary Calculation

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Django
- 🗄️ MySQL
- 🎨 HTML, CSS, JavaScript
- 🌿 Git & GitHub

## 🚀 Run the Project

```bash
git clone https://github.com/Harshalanka522/Employee-Management-System-Django.git

cd Employee-Management-System-Django

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
